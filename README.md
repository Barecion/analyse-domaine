## Mes 2 domaines préférés

### Domaine 1 : Graphisme

- Expérience : Je dessine sérieusement depuis 2020 et j'ai même un portfolio qui m'avait été fait accepter au programme de Art Visuel au Dawson College.
- Logiciels et outils : J'aimerais apprendre comment utilisé Adobe Photoshop comme un professionel.
- Pourquoi il m'intéresse : J'ai toujours voulu faire des couvertures pour des jeux vidéos. C'est la raison numéro 1 que j'achète les éditions physiques.
- Travailler dans ce domaine : Oui, puisque j'adorais prendre des jours en travaillant pour les plus petits détails dans un poster ou un "game cover".

### Domaine 2 : Jeux vidéo

- Expérience : Je n'ai aucune experience mais je pense en commençant par le codage dans web pour le 2D pourrait m'inicier.
- Logiciels et outils : Quand je maîtriserais le CSS, je pourrais aller en JavaScript et ensuite commencer sur Blender pour le 3D.
- Pourquoi il m'intéresse : J'aimerais raconter mes histoires à travers les jeux vidéos comme la série Metal Gear Solid et Kingdom Hearts.
- Travailler dans ce domaine : Oui, puisque si je travaille en équipe dans ce domaine je pourrais avoir une des meilleurs experiences de vie. Ensuite, j'aimerais créer mon propre studio de developpement plus tard dans ma vie.
